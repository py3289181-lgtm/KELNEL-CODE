# ⚡ KernelCode IDE

An ultra-fast, modern, browser-based code editor inspired by VS Code, powered by Monaco Editor & React.

---

## 🚀 Live Access
The development server is running live:
- **Local URL:** [http://localhost:5173/](http://localhost:5173/)
- **Network URL:** Accessible on your local network!

---

## 🛠️ Key Features Included

### 1. Monaco Editor (VS Code Engine)
- Real VS Code editing experience with IntelliSense, auto-closing brackets, syntax highlighting.
- Minimap scroll preview.
- Line numbers, code folding, smooth caret blinking, multi-cursor editing.

### 2. Multi-Tab & File Management
- Open, close, switch tabs with dirty state indicators (●).
- Full File Explorer tree with language-specific icons.
- Instant file creation directly from the sidebar.

### 3. 50+ Built-in Themes & Custom Theme Builder
- **Dark Themes:** VS Dark+, One Dark Pro, Dracula, Tokyo Night, Monokai, Nord, Gruvbox Dark, Material Dark, GitHub Dark, Catppuccin Mocha, Night Owl, Palenight, Synthwave 84, Cobalt2, Shades of Purple, Ayu Dark, Andromeda, Panda, Radical, Forest, Cyberpunk, Darcula, Atom One Dark, Neon Dreams.
- **Light Themes:** VS Light, GitHub Light, Solarized Light, Quiet Light, Ayu Light.
- **High Contrast:** High Contrast Dark.
- **Font Switcher:** JetBrains Mono, Fira Code, Cascadia Code, Source Code Pro, Consolas, and more.
- **Interactive Theme Builder:** Customize editor, sidebar, panel, and text colors with instant preview.

### 4. Integrated Terminal Panel
- Bottom panel with **Terminal**, **Problems**, **Output**, and **Debug Console**.
- Interactive simulated command shell (`help`, `ls`, `pwd`, `git status`, `node --version`, `clear`, etc.).
- Command history navigation (Arrow Up / Arrow Down).

### 5. Live HTML/CSS/JS Preview
- Split preview panel with real-time rendering of your code.
- Instant iframe sandbox execution with refresh support.

### 6. Git Source Control UI
- Track modified, untracked, and staged files.
- Commit messages, push & pull actions, branch indicators.

### 7. Extensions Panel
- Marketplace-style extensions UI (Prettier, ESLint, GitLens, Live Server, etc.) with install/toggle support.

### 8. Command Palette & Shortcuts
- **Ctrl + Shift + P** / **Ctrl + P**: Quick Command Palette.
- **Ctrl + B**: Toggle Sidebar.
- **Ctrl + `**: Toggle Terminal Panel.
- **Ctrl + S**: Save File.
- **F11**: Zen Focus Mode.
